## 1. Agent 系统重构（3.0.0 M1）

### 1.1 目标态

应用内 Agent 只剩两类展示：

1. **思迹助手**（唯一内置）：固定、不可编辑不可删除、默认激活。
2. **我的 Agent**（自定义）：来源两个入口——
   - 模板创建：Agent 模板区点击模板 → 表单预填 → 可改 → 保存；
   - AI 对话创建：对思迹助手说「创建一个 XX Agent」→ AI 生成方案 → 确认卡 → 落库。

现状的两个内置场景 Agent（职场参谋、情感顾问）从内置名单中移除。

### 1.2 内置移除与能力保留

- `store/agent.js` 删除 `PRESET_AGENTS`（职场参谋、情感顾问），`agents` 初始化为 `[BUILTIN_SIJI] + 自定义`；`restoreFromStorage()` 同步。
- 两个 Agent 的人设（systemPrompt + 五段 skillPrompts：记忆/关系/决策/计划/总结）合并后转入 `utils/agent-templates.js` 的 `PRESET_TEMPLATES`，成为两个新模板。能力不丢，需要时点模板实例化为自定义 Agent。
- `utils/ai/skills.js` 的 `BUILTIN_AGENT_SKILLS` 只保留 `siji` 键；`SKILL_REGISTRY` 技能注册表保留（自定义 Agent 白名单仍用它）。
- 模板库最终清单（2 个，用户 2026-09-04 决策）：心理咨询师、情感顾问。原职场参谋（内置）不转模板直接移除；健身教练/财务顾问/学习伙伴/极简助手模板废弃。
- 模板卡片上标注「点击创建」，点后进入现有 `agent_add?mode=create&tpl=名称` 预填流程（该机制已存在，直接复用）。

> 执行状态：1.1/1.2 已按上述决策落地（store/agent.js 仅 siji；PRESET_TEMPLATES 仅 2 个；skills.js 仅 siji）。

### 1.3 AI 对话直接创建 Agent

新增工具（新建类 action，按 AGENTS.md 规则 CORE_ACTIONS 与 TOOL_DEFINITIONS 双注册）：

```
create_agent { name, description, systemPrompt, skills[], icon }
```

流程：
1. 用户说「创建一个英语陪练 Agent」「帮我弄个考研规划师」；
2. AI 按创建规范产出方案（含白名单内 skills、预设图标集内 icon、systemPrompt 上限 4000 字符）；
3. 不直接落库，返回「创建确认卡」：名称/简介/技能/人设摘要；
4. 用户点「确认创建」→ `store.createAgent()` 落库并持久化；
5. 成功后提示：已创建，可在对话顶部切换器选用或在「设置 → Agent」中编辑。

实现要求：
- `utils/ai/tools.js` + `prompt-actions.js`：注册 `create_agent` 及参数 schema；
- 执行分发：走 store 执行链（如 `store/executors/agent.js`），校验 icon 必须在预设图标集、skills 必须在 `SKILL_REGISTRY` 白名单、systemPrompt 超限截断；
- 确认机制：复用现有动态确认链路；若现链路只支持金额阈值，则为 create_agent 增加「必须确认」标记（改 `autoExecutor.js` / 确认判定处，扩展为非金额必确认）；
- 对话内引导规范写入 prompt 行为规则：「先确认用途 → 一次给出完整草案 → 等用户确认才调用 create_agent」。

> 执行状态：create_agent 已注册并走统一确认链路 —— 确认卡确认后由 store/data.js 分发到 store/executors/agent.js 落库；校验共用 utils/ai/tools/agent.js buildAgentPayload。

### 1.4 存量兼容

- 用户已创建的自定义 Agent（`siji_agents`）全部保留，不做清除迁移；
- 旧会话中引用 `workplace_advisor` / `relationship_advisor` 的：运行时按 id 找不到时回退思迹助手（现有 getAgentSystemPrompt / activeAgent 已有兜底），不回放旧人设，不白屏；
- 图标文件（-v2）与 `normalizeAgentIcon()` 映射全部保留；
- 数据备份：`siji_agents` 已在 AI 域备份范围，无需改 export.js。

### 1.5 UI 改动

- `pages/settings/sub/agent.vue`：改为三段布局——思迹助手固定卡（只读详情）/ Agent 模板区（点击创建）/ 我的 Agent（编辑、删除、设为当前）；空态提示「对思迹助手说：创建一个 XX Agent」；
- `pages/settings/sub/agent_add.vue`：保留 create/edit/view 三模式；ICON_OPTIONS 保留 10 个图标（职场/情感图标供新模板用）；skills 勾选改为白名单展示；
- `components/chat/AgentSwitcher.vue`：列表自动变为 思迹助手 + 我的 Agent；无自定义 Agent 时仍可切换（仅一项时可收起入口）；
- `pages/settings/index.vue` Agent 入口文案由「Agent」改为「Agent 与模板」。
- `pages/settings/sub/agent.scss`：模板网格样式（两列卡片 + 「点击创建」角标），遵守零阴影零渐变。

## 2. 版本历史折叠（3.0.0 M2）

现状：version-history.vue 平铺 44 条小版本（1.0.0 – 2.3.21），每条卡片可点进 detail。
目标：按大版本分组，三个大版本（1.x / 2.x / 3.x）各自可折叠。

- `pages/settings/sub/version-history.vue` 重构：
  - 运行时把 history 按主版本号分组：`v3.x`、`v2.x`、`v1.x`；
  - 每个大版本组渲染一个折叠头：版本范围（v1.0.0 – v1.3.0）+ 更新条数 + 折叠箭头；
  - 点击组头展开/收起组内小版本卡片（沿用现有 v-card），点击小版本仍进 detail；
  - 默认状态：最新的 v3 组展开，v2 / v1 组收起；组内超出 5 条时先显示最近 5 条 + 「展开全部 N 条」；
  - 折叠状态用组件内 ref 即可，不持久化；
- `version-detail.vue` 不动；
- `version-data.js` 结构不动（每条自带 version/date/title/summary/categories），分组只按版本前缀；
- 3.0.0 发布时新增版本记录（v3.0.0），历史页自然出现第三组。

## 3. 对话沉淀闭环（3.0.0 M3，P0）

目标：解决「说了不沉淀、沉淀不可确认、变更变新增」三类根因问题。

### 3.1 写操作草稿卡（统一机制）

所有 AI 写操作（创建/修改记录、计划、账单、画像、关系）默认不直接落库，先出「草稿确认卡」：

- 卡片内容：标题、类型/标签、关键字段、正文截断预览（超出固定行数折叠）；
- 按钮：保存 / 修改（AI 按用户新要求重出草案）/ 放弃；
- 保存后 5 秒内可「撤销」（对刚写入项执行删除或回滚，标记 is_deleted 或恢复原值）；
- 设置中提供「AI 自动执行写操作」开关（默认关），开启后跳过一次确认。

实现落点：现有执行结果卡（ExecResultCard / autoExecutor 链路）扩展为可交互确认卡；新增通用 `utils/ai/draft-store.js`（草案暂存：会话内 ref + 一个 storage key 防页面切换丢失）。

### 3.2 分模块验收口径

| 模块 | 现状问题 | 3.0 行为 |
|------|----------|----------|
| 记录 diary | 标题与内容混乱、不自动生成标题 | AI 先拟标题再出草稿卡；正文卡片内折叠 |
| 计划 plan | 变更计划 = 新增计划；子计划体系混乱 | 强制规则：变更必须先 query_plan 定位原计划 id，走 update 而非 create；变更卡显示「原计划 → 新计划」diff 摘要 |
| 画像 profile | 自定义属性说了不新增 | smart_update_profile 升级为 diff 卡：新增/修改字段逐条列出，用户确认后写入并 bumpDataVersion |
| 账单/关系 | 少确认、误写后难撤 | 统一走草稿卡 + 撤销 |

### 3.3 AI 纠错与话语拆解（顺手修复）

- prompt 行为规则补充「先拆解后执行」：用户一句含多意图（如「记个账顺便定个明早的计划」）拆成多张草稿卡逐个确认；
- 纠错：用户说「不对，我说的是……」，AI 必须撤销前一张草稿卡或对已落库项走撤销，不得新增重复项。

## 4. 后续版本路线图（3.1 – 3.3）

### 3.1.0 最小行动管道（P1）
- 每次对话收尾，若存在未执行计划/想法，AI 收敛为「5 分钟内第一步」行动卡；
- 计划详情页增加「今天做第一步」按钮，完成即正向反馈（无连击无惩罚）；
- 计划性逃避识别：同一计划连续 3 次「只规划不执行」时，AI 提示缩小计划或删除。

### 3.2.0 金钱真相（P3）
- 账单自动归账完善（图片识别回归）；
- 每周一自动生成「三数字播报」：本周花了多少 / 还剩多少 / 最大一笔是什么；
- 播报卡可一键追问明细，不要求用户养成手动记账习惯。

### 3.3.0 状态觉察（P2）+ 社交预算（P4）
- 对话情绪低落识别写入状态时间线；连续低点提示休息（文案禁止「加油」类）；
- 社交能量预算：每周配额自设，AI 起草回复模板，关系提醒可延后不消失。
