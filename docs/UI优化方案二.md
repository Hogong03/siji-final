## P0-1 启动页深色适配（每次启动都撞上的刺眼白屏）

**现状（实测）**：pages/splash/index.vue 背景**固定 #E4E4E7 浅色**——深色用户每次打开 App 都要先看一屏亮白再进入深色界面，4.12 系列辛苦建立的深色体验在第一帧就破功。应用锁页（lock）已有深色块（#000000），splash 是漏网之鱼。
**方案**：splash 加深色块（html.theme-dark 嵌套 + MP @media 双路，背景 #18181B、logo 文字 #FAFAFA、"SIJI" 副标 #71717A）；配合 4.13.0 的冷启动预挂重试，首帧即为深色。lock 页顺手核对（已适配，跳过）。
**落点**：pages/splash/index.vue。
**量级**：半小时。

## P0-2 输入框文字随字号档位（字号体系的一致性补全）

**现状**：4.13.0 字号切换只覆盖"已发出的内容"（气泡/简报卡/阅读页）——**输入框里的字仍是标准号**，大字号用户"打字时小、发送后大"，同一句话两种字号割裂。
**方案**：InputArea 的 text-input 字号走 fontRpx(30) 内联绑定（输入区属阅读链路的入口，不属骨架）。
**落点**：components/chat/InputArea.vue。
**量级**：10 分钟。

## P1-3 计划卡倒计时徽标（简报卡的口径延伸到列表）

**现状（实测）**：计划过期/快到期只在进入对话时的简报卡里提醒；计划列表卡片上毫无痕迹——用户不进对话就看不到"还有 2 天到期"。
**方案**：PlanCard 标题行加**剩余天数徽标**，口径完全复用 utils/plan-alerts.js（过期=红「拖 N 天」、≤3 天=橙「剩 N 天」、其余不显示）——一个口径两处消费，不会出现简报说没过期、列表却标红的精神分裂。
**落点**：pages/plan/components/PlanCard.vue + 复用 plan-alerts.js。
**量级**：半天。

## P1-4 关键操作触觉反馈（vibrateShort 推广）

**现状（实测）**：vibrateShort 只在账单/计划的滑动操作里用了（useBillSwipe/usePlanSwipe）；而**打卡成功、长按呼出操作面板、删除确认**这三个高频关键时刻没有任何触觉反馈。
**方案**：三处接入 `uni.vibrateShort({ type: 'light' })`（既有先例同款）：① log_plan_checkin 成功回调；② 气泡长按 ActionSheet 弹出前；③ 对话删除确认弹窗出现前。平台差异：App 全支持、MP 部分支持、H5 大多静默失败（调用处全带 fail 静默，无成本）。
**落点**：scheduler 回调链 / MessageBubble.showActions / useConversationManager.handleDeleteConversation。
**量级**：1 小时。

## P1-5 记录列表卡片显示心情（闲置数据可视化）

**现状（实测）**：4.11.0 给记录加了 mood（1~5），详情页可选心情——但**列表卡片完全没展示**，用户打了心情看不到，数据闲置。
**方案**：卡片标题行右侧（缩略图同侧）加当前心情的小表情字符（mood 1~5 映射 😞😕😐🙂😄，20rpx），无心情不占位；与缩略图共存时的排布：心情在标题左、缩略图在右上，互斥不挤。
**落点**：pages/diary/list.vue（列表视图 + 时间线视图）。
**量级**：1 小时。

## P1-6 连续消息时间戳去重（对话流的阅读节奏）

**现状**：连续多轮对话里每条消息都带完整时间行，同一分钟内 3-4 条消息就有 3-4 个重复"11:06"——视觉噪音（第一轮 P0-1 的延伸：时间行收纳后这是消息区最后的重复元素）。
**方案**：`visibleMessages` 渲染时，**与上一条可见消息同一分钟**的后续消息不再显示时间行（已有 prev-role prop 通道可复用）；跨分钟/换角色才恢复显示。
**落点**：MessageBubble.vue（meta 行 v-if 判断，新增 showTime prop 由 index.vue 计算）。
**量级**：1 小时。

## P2-7 执行结果卡片视觉减重

ExecResultCard 目前「头部图标+标题+标签行+子计划列表+按钮」全框线堆叠，一条创建计划的执行卡比消息本身还高。方案：标签行收纳进标题行右侧、子计划默认折叠为「含 N 个子计划 ▸」可展开（数据已在 detail.children）、按钮保留。量级：半天。

## P2-8 热力图深色空格色

PlanHeatmap 空格子浅色下是浅灰、深色下沿用浅灰会形成整片亮点。方案：深色块内空格 #27272A、低活跃格降低不透明度。量级：半小时（需真机核对色阶）。

## P2-9 情绪与支出同图对照

stats 页情绪曲线（4.11.0）与支出曲线分图展示；叠加到同一张图（双序列 + 图例）能看出"花钱多的那几天心情如何"的自相关。SijiChart 已支持多序列。量级：1 小时（数据都现成）。
