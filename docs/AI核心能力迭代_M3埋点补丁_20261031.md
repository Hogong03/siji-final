## 2. 统计字段说明

### 2.1 `siji_advice_seen`（原有，口径不变）

每个方向 id：`shown / accepted / ignored / rejected / lastAt / rejectAt`，上限 200 个 id。

- `shown`：面板实际展示（自动 + 手动都算，用于冷却）
- `accepted`：点了方向卡（跳转/预填）
- `ignored`：关闭面板时**展示过但没动作**
- `rejected`：点了「不相关」

冷却：拒绝 14 天 > 忽略满 3 次 30 天 > 普通曝光 7 天。

### 2.2 `siji_advice_silence`（原有）

按 reason 计数：`not-enough` / `no-candidate` / `low-no-gentle` / `energy-very-low`。只在自动入口、且签名门控放行之后记录。

### 2.3 `siji_advice_diag`（新增，按日聚合）

```js
{ days: { 'YYYY-MM-DD': {
  autoEntries, autoShown, manualOpens, manualShown,
  considered, available, droppedNoRef, droppedDup, droppedCooldown,
  srcRule, srcLoop, autoDisabled
} } }
```

| 字段 | 含义 | 写入点 |
|---|---|---|
| `autoEntries` | 自动入口被尝试的次数（开关开、非首启、无遮挡） | `maybeShowAdvice` 入口 |
| `autoShown` | 自动入口实际展示的方向数 | 面板弹出时 |
| `manualOpens` | 手动打开次数 | `openAdvice` |
| `manualShown` | 手动入口实际展示的方向数 | 手动打开时 |
| `considered` | 候选池原始条数 | 每次 `buildAdvice` |
| `available` | 过完 ①~③ 后剩余条数 | 同上 |
| `droppedNoRef` | 依据层丢弃 | 同上 |
| `droppedDup` | 去重层丢弃（含同域） | 同上 |
| `droppedCooldown` | 冷却层丢弃 | 同上 |
| `srcRule` / `srcLoop` | 候选来源分布 | 同上 |
| `autoDisabled` | 用户主动关掉自动弹出的次数（设置变化，**不计 rejected**） | `disableAdviceAuto` |

**保留策略**：按本地日，保留最近 30 天；写入时剪掉更早的；单日固定 12 个整数字段，不随使用增长。
**不存**：候选原文、标题、证据文本、任何用户内容。
**失败策略**：所有读写 try 包住，统计失败不影响建议展示与点击。

## 5. 观察期口径（与状态记录一致）

- 沉默率 = `silence ÷ (silence + autoShown)`；**手动打开不进分母**。
- 接受率/忽略率/拒绝率的分母是 `shown`（含手动展示），与沉默率分母不同，读数时别混用。
- 各层拦截是「每次 build」计数，含手动打开时的 build；诊断分层问题时以比例看，不看绝对值。
- 全局关闭后 `autoEntries` 停止增长，属正常；这时沉默率不再更新，不要当成系统变沉默。
