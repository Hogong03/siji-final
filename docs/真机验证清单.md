# 思迹 App 端真机验证清单

> 用法
> - 范围：App 端（Android 优先；iOS 真机需 Mac + Xcode + 证书，Windows 环境无法验证，用 Android + H5 近似覆盖）
> - 每次发版：过「0. 逻辑层前置」+「1. 发版 Smoke」，约 10 分钟
> - 新大版本 / 动了平台相关代码（条件编译点）：加过「2. App 端专项清单」对应小节
> - 验证完在「4. 验证记录」登记一行，按版本迭代维护
> - 环境：HBuilder X ≥ 3.8.7；编译前删 `unpackage/dist` 强制重编译；设备用真机（USB 调试）或模拟器（MuMu / 雷电 / AVD），上架前必须真机过一遍
> - HBuilder 内置浏览器 ≠ 真机：内置浏览器里过的项不算验证通过

## 1. 发版 Smoke（每次必过）

### 1.1 启动链路
- [ ] 覆盖安装启动：splash 1.6s → 已同意协议直接进主界面；首启出 disclaimer；已设 PIN 进锁屏

### 1.2 Agent 工具循环
- [ ] 发「记一笔午饭 30 元」→ 工具执行、结果卡正确、账单页可见
- [ ] 金额 ≥ 500（如「记一笔房租 1500」）→ 弹确认卡，确认后才写入（动态确认阈值）
- [ ] 长回复流式逐字输出不卡死（App 走 `enableChunked` 真流式，3.5.11 崩溃点）
- [ ] AI 纠错闭环（4.8.2 回归）：说「看下这个月的账单，把那笔 30 块改成 35」→ AI 先 query（结果带 id）再 update 成功、账单页金额已变
- [ ] 说一句包含大额的话（如「记一下房租五千」）→ 出确认卡；确认/取消都正常（兜底路径也走确认闸门，4.8.2）

### 1.3 进入总结伪对话（3.5.19–3.5.21）
- [ ] 杀进程重开 → 新对话里总结消息落底、开场白被覆盖（不叠加两条）
- [ ] 预置按钮逐个点：看计划 → /pages/plan/index（有事件时「查看详情」→ /pages/plan/records）；看新记录 → /pages/diary/list；看账单 → /pages/bill/index；记一笔 / 写个记录 / 定个计划 → 输入框 prefill 而非直接发送
- [ ] 点「返回旧对话」→ 切回旧对话，且只带总结的伪对话壳被销毁（会话列表不残留）
- [ ] 杀进程重开 → 空对话上点「回去接着聊」→ 跳到真正的上一次对话而非开场白壳（3.6.1 回归点）

### 1.4 撤销
- [ ] 记账 / 记录 / 计划各落一条 → 撤销 → 对应页面消失（软删生效）

### 1.5 深浅色
- [ ] 跟随系统切深色：聊天、账单、计划、设置四页快速扫一遍，无白底残块

前提：**必须自定义基座或云打包**（勾选本地插件 siji-keepalive），标准基座里开关会置灰并显示「当前安装包不支持」。4.35.2 起插件带原生模块（SijiKeepAliveModule），JS 走 `uni.requireNativePlugin` 正路 + plus.android 反射兜底。

- [ ] 装包后进「设置 - 提示与提醒」→「后台运行」组存在，开关可点（不是置灰态）
- [ ] **模块路径（4.35.2 新增）**：打开开关后 `adb logcat | grep keepalive` 出现「前台服务已启动（模块路径）」——若出现「反射路径」说明模块桥没通（记录机型与 HBuilderX 版本，反射兜底仍然算通过，但模块问题要回报）
- [ ] 打开「后台常驻」→ 通知栏立刻出现一条常驻通知：标题「思迹正在后台运行」，**不响不震、不可划掉**，点它回到 App
- [ ] **通知小图标**：常驻通知左侧图标在系统里显示是否正常（当前用应用图标，规范上小图标应为单色 —— 若被裁成灰块/方块，需出专用单色图标）
- [ ] 关闭开关 → 常驻通知立刻消失，`adb shell dumpsys activity services <包名>` 里没有 SijiKeepAliveService
- [ ] 建一个 5 分钟后的计划提醒 → 按 Home 退后台 → 到点仍出提醒（进程没被杀，走 60s 轮询）
- [ ] 从最近任务**划掉**思迹 → 到点仍收到通知栏提醒（走 4.22.0 本地推送；进程真被杀也送达）
- [ ] 划掉后重开 App → 常驻通知自动回来（App.vue onShow 的 syncKeepAlive 校正）
- [ ] 点「允许后台运行」→ 跳到系统电池优化列表 / 应用详情页（小米 / 华为 / OPPO 机型各自确认跳转目标是否可操作）
- [ ] Android 13+：系统设置里关掉思迹的通知权限 → 常驻服务自行停止且**不崩溃循环**（重新打开开关不闪退）
- [ ] Android 14 / 15 机型：服务能起来（specialUse 类型声明生效），长时间挂着不被系统按 6 小时上限掐掉
- [ ] 耗电：挂 8 小时后系统「电池用量」里思迹占比无可感知抬升（前台服务本身不持 wake lock）
- [ ] 关闭开关后 `siji_keepalive_enabled` = '0'（杀进程重开也不会自己拉起）
