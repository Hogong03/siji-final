# 思迹 App 端真机验证清单

> 用法
> - 范围：App 端（Android 优先；iOS 真机需 Mac + Xcode + 证书，Windows 环境无法验证，用 Android + H5 近似覆盖）
> - 每次发版：过「0. 逻辑层前置」+「1. 发版 Smoke」，约 10 分钟
> - 新大版本 / 动了平台相关代码（条件编译点）：加过「2. App 端专项清单」对应小节
> - 验证完在「4. 验证记录」登记一行，按版本迭代维护
> - 环境：HBuilder X ≥ 3.8.7；编译前删 `unpackage/dist` 强制重编译；设备用真机（USB 调试）或模拟器（MuMu / 雷电 / AVD），上架前必须真机过一遍
> - HBuilder 内置浏览器 ≠ 真机：内置浏览器里过的项不算验证通过

## 1. 发版 Smoke（每次必过）

### 1.1 启动链路
- [ ] 覆盖安装启动：splash 1.6s → 已同意协议直接进主界面；首启出 disclaimer；已设 PIN 进锁屏

### 1.2 Agent 工具循环
- [ ] 发「记一笔午饭 30 元」→ 工具执行、结果卡正确、账单页可见
- [ ] 金额 ≥ 500（如「记一笔房租 1500」）→ 弹确认卡，确认后才写入（动态确认阈值）
- [ ] 长回复流式逐字输出不卡死（App 走 `enableChunked` 真流式，3.5.11 崩溃点）

### 1.3 进入总结伪对话（3.5.19–3.5.21）
- [ ] 杀进程重开 → 新对话里总结消息落底、开场白被覆盖（不叠加两条）
- [ ] 预置按钮逐个点：看计划 → /pages/plan/index（有事件时「查看详情」→ /pages/plan/records）；看新记录 → /pages/diary/list；看账单 → /pages/bill/index；记一笔 / 写个记录 / 定个计划 → 输入框 prefill 而非直接发送
- [ ] 点「返回旧对话」→ 切回旧对话，且只带总结的伪对话壳被销毁（会话列表不残留）
- [ ] 杀进程重开 → 空对话上点「回去接着聊」→ 跳到真正的上一次对话而非开场白壳（3.6.1 回归点）

### 1.4 撤销
- [ ] 记账 / 记录 / 计划各落一条 → 撤销 → 对应页面消失（软删生效）

### 1.5 深浅色
- [ ] 跟随系统切深色：聊天、账单、计划、设置四页快速扫一遍，无白底残块

## 2. App 端专项清单（平台差异全量，动到对应模块才重过）

### 2.1 AI 流式与网络（utils/ai/chat-chunked.js / agent-transport.js）
- [ ] 流式中途断网 → 有错误提示、可重试（useRetryBar），恢复后错误上报 flush
- [ ] 未配 API Key → 离线降级回复，不白屏不转圈死
- [ ] 换非智谱厂商（DeepSeek / 通义）发起联网搜索 → 仍可用（3.5.18 与聊天厂商解耦）；搜索开关关 → web_search 不注入
- [ ] 429 / 超时 → 重试生效（指数退避），401 不重试直接提示换 Key

### 2.2 提醒与通知（utils/reminder/notifier.js）
- [ ] 建一个 5 分钟后的计划提醒 → 到点弹通知 + 震动（plus.push）
- [ ] Android 13+ 首次触发时申请通知权限（POST_NOTIFICATIONS）
- [ ] 静默时段（22:00–08:00）到点不弹

### 2.3 隐私与安全
- [ ] Android 防截屏 FLAG_SECURE：系统截屏得到黑屏（App.vue:100-122）
- [ ] PIN 锁：输错锁定倒计时；退后台再回前台触发锁

### 2.4 录音与语音转写（utils/ai/recorder.js / transcribe.js）
- [ ] 录音 25s 自动停；转写返回文字（智谱 ASR multipart 直传）
- [ ] 取消录音不残留半个消息

### 2.5 图片（utils/image.js）
- [ ] 记录选图 → 压缩 → 保存进 `_doc/` → 杀进程重开图片仍显示
- [ ] vision 模型图片识别可用（DeepSeek / 智谱）

### 2.6 备份与导出（utils/backup-file.js / export.js / export-diary.js）
- [ ] 导出备份 json → 文件落 `PRIVATE_DOC/backup/` 或可下载分享
- [ ] 导入备份 → 数据恢复完整；API Key / PIN 不被导入覆盖（BACKUP_EXCLUDE_KEYS）
- [ ] 导出日记 / 数据管理页导出 csv/json 正常

### 2.7 图标与资源缓存（static/ 全部 -v2 资源）
- [ ] 覆盖安装（不卸载）后 tabBar / provider / agent 图标全部为新图（-v2 防缓存机制的实测项）

### 2.8 存储与配额（store/chat/persist.js）
- [ ] 会话聊到 20+ 条 → 对话尺出现（3.5.17），点刻度直达、拖动节流、视口指示随滚动
- [ ] 多会话 + 长对话并存 → 老会话打开不丢消息（85% 配额逐个裁老会话）

### 2.9 布局与交互
- [ ] 键盘顶起：聊天输入区不被遮挡、不跳动（fixed 定位）
- [ ] 全面屏底部手势条不遮挡输入区 / 主按钮（safe-area-bottom）

### 2.10 版本更新检查（utils/version-check.js）
- [ ] 不误报、触发不崩；App 端版本号读资源包版本（3.6.2 后反馈导出头部不再是 v1.0.0）

### 2.11 读文件与读网址（3.6.0–3.6.2，utils/files/ + utils/ai/read-*.js）
- [ ] **Android** 点聊天输入框「文件」按钮 → 弹出系统文件选择器（3.7.5 新增，零插件）→ 选一个 txt/csv → 附件条出现「文件名 · 大小 · N 行」，发送后能就文件内容追问
- [ ] Android 选 pdf → 走文档解析后端（没配 Moonshot Key 时给出去哪儿配的提示，不是静默失败）
- [ ] Android 选择时点返回/取消 → **不弹任何提示**（静默返回，别出现空 toast）
- [ ] Android 选一个 > 5MB 的文件 → 选择阶段就被拦下并说明原因（不拷贝、不卡顿）
- [ ] **iOS** 点「文件」按钮 → 走提示（截图识别 / 粘贴文字 / 装原生插件）—— iOS 无零插件路径，属已知限制
- [ ] H5 / 小程序端：选 txt / md 文件 → 本地直读成功，正文进消息 fileText 字段、气泡原话不含全文；追问能问上文件内容（历史保留最近一条带文件消息的正文）
- [ ] H5 端选 pdf / doc / xlsx / ppt → 走 Moonshot 文档解析后端取回纯文本
- [ ] 发一个含中文的网址消息（如 `https://www.deepseek.com/阅读这个网址`）→ 只读网址本身，尾巴中文不被当路径（3.6.2 回归点）
- [ ] App 端直连抓取失败 → 失败原因显示超时 / 拒绝抓取 / 证书问题，而不是「跨域限制」（3.6.2 回归点）
- [ ] 联网搜索 / 读网页的执行卡只留摘要行（「已联网搜索 · N 条结果」「已读取网页 · 域名（N 字）」），导出的开发者反馈里不再整段是网页正文
