## 0. 版本定位

| 版本 | 范围 | 优先级 |
|------|------|--------|
| 3.3.0 | A 最小行动闭环 + B 计划性逃避温和点破 v1 + C 图片识别泛化 + 历史遗留回归 | 本次全部 |

执行原则：
- 铁律 1：不制造失败感——B 只做「非评判观察 + 可选项」，零评分/打卡/催促文案。
- 铁律 4：计划必须小——A 把「拆到 5-15 分钟可执行的一步」落进计划结构与 AI 行为。
- 铁律 5：识别规划与行动——执行日志让 AI 分得清「又想了 10 分钟」和「做了 5 分钟」。
- 铁律 6：用户只做两件事（说话、点确认）——执行记录埋点自动化，不新增输入负担。
- 纯本地、无推送；依赖模型新能力的部分先验证再定范围（C0 先行）。

## 2. A 最小行动闭环（P1）

### 2.1 目标
一次对话后，屏幕上有一个可点的下一步；点下去 = 完成一次 5-15 分钟小步并自动落执行日志；AI 复盘/点破时引用日志而非空谈。

### 2.2 落地拆解
- A1 数据（最小侵入，D2=B）：
  - 计划/子计划记录新增字段：`est_minutes`（AI 拆解建议档位 5/10/15）、`done_at`（status 置 2 自动写时间戳）、`executions: []`（最近 50 条执行日志，`{ action: 'done'|'downsize'|'pause', at, note? }`）。
  - 完成入口统一走既有 status 切换分支：置 2 时写 `done_at` + push `{action:'done', at}`；父计划聚合子计划日志用于复盘。
- A2 AI 侧：
  - `utils/ai/tools/plan.js` subtasks schema 提示：单步超过 15 分钟 → 继续拆小；`est_minutes` 字段进 schema。
  - `utils/ai/prompt-actions.js` 补行为句：「拆计划必须把第一步收敛到 5-15 分钟可执行」「收到『执行/开始/做第一步』→ 引用该子计划而非重新规划」。
  - `tests/correction-regression.test.js` 追加 2 条 mock 序列（规划即拆小 / 更新不重建）。
- A3 UI 侧（D1=C 双入口）：
  - `pages/plan/detail.vue`：计划未开始且有子计划时，顶部渲染「下一步：〈子计划标题〉 · 约 X 分钟 → 标记完成」单卡（tap 即置 status=2 并落日志）；已有执行历史显示「上次执行：〈时间〉」灰字。
  - 聊天内可点卡片：AI 创建/更新计划后，复用 `components/chat/ExecResultCard.vue` 通道输出「下一步」按钮（点击直达计划详情页该子计划；或直接在该卡内完成）。
  - 计划列表 `PlanCard` 不加新元素。

## 3. B 计划性逃避温和点破 v1

### 3.1 目标
同一计划连续「只规划不执行」时，AI 在对话中温和点破：非评判观察 + 可选项（缩小范围 / 换更小一步 / 暂停计划 / 今天不做也行），零催促。

### 3.2 落地拆解（D3=A / D4=A 口径）
- 触发判定（纯规则，本地埋点，不学用户）：
  - 近 90 天内该计划被 AI 更新/扩展 ≥ 3 次（`updated_at` 变化 + executions 无新增）且无任何 `done_at`；
  - 距上次「计划类对话」> 3 天；
  - 用户下次聊到该计划/相关主题时触发（仅对话内，无推送/横幅）。
- 实现：prompt 动态段注入「近 7 天执行摘要（计划级聚合 `executions`）」；点破模板句固化（观察式 + 可选项式两条），经回归断言禁止「你应该/加油/又没做」。
- 不新增系统通知、不做详情页横幅（D3=A）。

## 4. C 图片/截图识别泛化（先验证后定范围）

### 4.1 现状与已知痛点
- 链路已具备两步组合；历史反馈：聊天截图小字过糊（2026-08-30 已升 1568px/90）、失败时兜底文案、Web 端选图偶发下载行为（D6=A 并入本次修复）。
- 当前单图；真实场景多为「连发 5 张聊天截图再总结」。

### 4.2 两阶段（D5=B 口径）
- C0 能力验证：取 5-8 张真实截图样本（清晰度梯度），H5 现有链路跑通，对比 deepseek-v4-flash-vision-exp 与 glm-5.3-flash（需智谱 key 已配置）转写准确率，产出结论表 → 定 C1 范围。
- C1（按验证结果）：多图逐张识别合并（InputArea 多选 → 逐图 vision → 合并「图1/图2」文本块）+ 识别结果注入格式统一 + 失败提示/重试优化。
- 若 C0 显示两模型均不达标 → C1 收缩为「prompt 提示词优化 + 失败提示改进」，多图合并延后。
