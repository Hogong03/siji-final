# 思迹竞品对比与差距方案（2026-10）

> 结论先行：思迹的「全域对话式 AI 助手 + 数据本地 + 自带 Key」组合在市场上没有直接对标产品——竞品都在单域做到深（Cleo 只管钱、Rosebud 只管日记、Moo 只管情绪）。真正的差距不在功能广度，而在三件事：**开箱即用度（免 Key）、数据安全网（云备份）、记录的富媒体与回顾体验**。以下按影响排序。

---

## 一、竞品分四类对标

| 类别 | 代表产品 | 核心体验 | 变现 | 对思迹的启示 |
|---|---|---|---|---|
| AI 引导日记 | Rosebud、Mindsera（$14.99/月）、Stoic、Life Note、InnerOS | AI 主动提问引导写日记、追问深入、自动生成反思与主题标签；Mindsera 定位"精神健身房" | 订阅 $10~15/月，AI 功能全在付费墙内 | 引导式追问是留存利器；思迹的 AI 目前纯被动响应 |
| 情绪日记 | Moo日记（AI 会员 NT$690/年）、心岛日记、Daylio | 心情打点 + 情绪趋势图表 + AI 陪伴回复；心岛偏社区、Daylio 纯工具 | 订阅 + 虚拟商品 | 情绪曲线是高频回访入口；思迹有能量感知但没有可视化闭环 |
| 记账 | Cleo（chat-first money coach）、咔皮/阿兜（自动同步账单）、小薯条（语音记账）、鲨鱼/随手记/iCost | Cleo 用聊天气泡分析消费、甚至"毒舌"催储蓄；国内趋势是绑定支付工具自动记账 + 语音记账 | Cleo 免费核心 + 订阅（$45~199/年）；国内多为买断/免费 | 语音记账已是被验证的记账形态（思迹 2.3 上线过又移除）；对话分析消费思迹已有（query_stat） |
| 本地优先/隐私系 | Diarly（本地优先+iCloud）、DailyVox（无服务器无账号）、Joplin（WebDAV/坚果云）、Obsidian | 卖点是"数据在你手里"：无账号、可导出、可选加密 | 买断或免费 | 思迹的本地存储是这个赛道的核心卖点，但要补「同步/备份」短板才成立（纯本地=换机即丢） |

共性观察：2026 年市场已从"手动记录"转向"AI 自动化 + 对话式 + 订阅制"；所有竞品 AI 都是开箱即用（官方承担模型成本，靠订阅回收）。

## 二、思迹的反向优势（保持并放大，写进介绍站）

1. **全域一体**：记账/记录/计划/人脉/决策一个对话入口——竞品全是单域，用户不需要装四个 app。
2. **数据不出设备**：全量本地存储，竞品的云端账单授权与日记上云都有隐私疑虑。
3. **零订阅**：自带 Key、成本透明，对比 Mindsera $15/月、Moo NT$690/年。
4. **AI 行为可自检**：30 条语料跑分 + 确认闸门 + 撤销，市面上没有第二个产品敢公开量化自家 AI 的准确率。

## 三、差距与解决方案（P0 先做）

### P0-1 AI 开箱即用度：必须自己申请 Key（最大流失点）
现状：新用户下载后如果不会申请 API Key，AI 能力为零；竞品全部开箱即用。
方案（三步，按成本递增）：
1. **首启动引导流**（零成本，先做）：新对话冷启动检测无 Key → 全屏引导页（选厂商 → 一键跳转对应申请页 → 粘贴 Key → 自动验证一次真实请求 → 完成回调）。落点：`utils/ai/chat-helpers.js` 空态判定 + 新页 `pages/settings/sub/key-guide.vue` + `pages.json`。
2. **试用额度**（轻服务端）：自建一个极薄的代理（CloudBase 云函数即可，按设备 ID 限次，如每天 20 次），无 Key 用户可体验完整 AI；引导页挂"先试试"。依赖：需要服务器与风控，接受成本再上。
3. **免费模型通道**：智谱 flash 系列若有免费档位，作为"免 Key 默认厂商"写进引导（需复核各厂商当前免费政策，每年 1 月的维护清单加一项）。

### P0-2 数据安全网：纯本地的"换机即丢"
现状：本地存储是卖点，但没有跨设备备份就变成风险；竞品至少有云同步。
方案（分期，先零依赖后网络）：
1. **自动本地备份**（先做）：App 端定期把全量 JSON + 图片清单 zip 到 `_doc/backup/`，保留最近 3 份；恢复入口放数据管理页。落点：`utils/storage/export.js` 扩展（备份分域键已存在）。
2. **WebDAV 同步**（第二步）：坚果云免费额度足够日记/账单体量；WebDAV 就是 HTTP PUT/GET/PROPFIND，App 端 `uni.request` 可直接实现，**H5 端受跨域限制需声明仅 App/MP 可用**；同步前 zip + AES 加密（密钥用户自设，服务端零知识）。落点：新增 `utils/sync/webdav.js` + 设置页「云备份」卡。
3. 冲突策略先做"整包覆盖 + 恢复前自动留档"，不做字段级合并（成本高且易错）。

### P1-3 记录富媒体：照片日记
现状：图片仅作为 AI 识别输入，记录本身纯文本；Moo/Day One 的照片九宫格是日记类标配。
方案：`create_diary` 增加 `images` 字段（App 端存 `_doc/diary-img/`、MP 存 `USER_DATA_PATH`、H5 存 base64→IndexedDB 思路同现有图片链路）；列表缩略图、详情九宫格、AI 描述入正文。落点：`store/executors/diary.js` + `pages/diary/` + 备份键登记。注意 App 端图片缓存规矩（改名不换内容）。

### P1-4 情绪趋势闭环
现状：AI 有能量感知段，但用户看不到自己的情绪曲线。
方案：记录落库时让 AI 顺带产出 `mood`（1~5）字段（提示词加一个字段 + 执行器透传），统计页用现有 SijiChart 画月度情绪折线 + 与消费/打卡的叠加视图。落点：`store/executors/diary.js`、`pages/bill/stats.vue` 或记录统计页。

### P1-5 语音记账（可选，产品决策）
现状：2.3 上线过语音（recorder/transcribe 全套），v11 输入框精简时移除；小薯条等已验证"语音记账"是高频形态。
方案：从 git 历史（2.3.x tag）恢复 `utils/ai/recorder.js` + `transcribe.js`，入口做成输入框左侧麦克风（默认隐藏，AI 能力页可开）。三端差异：H5 MediaRecorder / App+MP getRecorderManager，代码当时已写好，恢复成本低，但需要先回答"当初为什么删"（输入区克制）——建议作为「AI 能力」注册表里的一个开关，默认关。

### P1-6 月报/年报（传播利器）
方案：基于 `query_stat` + 记录/打卡聚合，用 canvas 绘制分享长图（数据大字报风格：本月支出 top、打卡 streak、记录字数、情绪均值），一键保存/分享。落点：新增 `pages/stats/report.vue` + `utils/report-canvas.js`。竞品 Wrapped 式分享是拉新主通道，思迹目前没有任何分享物料。

### P2-7 快捷入口（小组件/分享接入）
- 系统分享接入：其他 app 选中文字 → 分享到思迹 → 自动开一条记录（Android `intent` / iOS extension 需原生插件，uni-app 插件市场有现成；小程序不可用）。
- 桌面小组件同理需原生插件，列为远期；先做**通知栏快捷动作**（Android，配合现有提醒系统：点通知直达打卡已具备）。

### P2-8 引导式日记模式（对标 Rosebud）
方案：AI 能力注册表加"引导追问"开关（默认关）；开启后提示词要求 AI 在记录类回复末尾附一个深入追问。落点：`utils/ai/features.js` 注册表 + `prompt-builder.js` 段注入——现有架构半小时级工作量。

### P2-9 打卡 streak 游戏化
现状：有里程碑回执，无连续天数/徽章体系。方案：`log_checkin` 时算 streak（现有 checkin 统计已有数据），里程碑回执文案升级为"连续 N 天"；徽章页远期。

## 四、建议落地顺序

1. 本周可做（零服务端依赖）：P0-1 引导流 → P0-2 自动本地备份 → P2-8 引导追问开关
2. 下一步：P1-3 照片日记 → P1-4 情绪曲线 → P1-6 月报长图
3. 需要决策/资源：P0-1 试用额度（服务端成本）、P0-2 WebDAV（同步策略）、P1-5 语音（与输入区克制原则的取舍）
4. 远期：P2-7 原生插件类
