# 思迹图片识别能力验证（3.3 C0，2026-09-06）

> 目的：在落地 C1（多图逐张识别合并）前，量化当前可用 vision 模型的截图转写准确率（D5=B：对比 DeepSeek V4 Flash Vision 与智谱 GLM-5.3 Flash）。
> 结论将决定 C1 范围：两模型均不达标 → C1 收缩为 prompt 优化 + 失败提示改进，多图合并延后；任一达标 → 实现多图合并。

## 1. 前置

- 应用版本：v3.3.0 起（含 3.2 的 1568px/90 压缩与两步组合模式）
- 环境：H5 真机浏览器或 iOS/Android 真机均可；每张样本固定用同一入口发送
- 模型配置（设置 → AI）：
  - DeepSeek：模型选「V4 Flash Vision(实验)」或文字模型（图片发送会自动走 vision 桥）
  - 智谱：需已配置智谱 API Key，模型列表含 GLM-5.3 Flash（原生多模态）
- 发图句式：`请识别并分析这张截图（图 N）`

## 2. 样本集（5-8 张，覆盖清晰度梯度）

| # | 样本 | 来源 | 期望关键信息 |
|---|------|------|--------------|
| 1 | 微信聊天截图（字号正常，白底） | 任意真实对话 | 参与人、最近 3-5 句内容、金额若有 |
| 2 | 微信聊天截图（小字号/群聊密集） | 群聊长对话 | 至少读出 5 句完整句子、消息顺序 |
| 3 | 短信/通知截图 | 系统通知 | 时间、发送方、金额/验证码类数字 |
| 4 | 收银小票照片 | 线下拍摄 | 金额、日期、商家、品类 |
| 5 | 支付宝/微信账单截图 | 账单页 | 金额、时间、对方名称 |
| 6 | 小红书/知乎文字截图 | App 内截图 | 标题 + 正文前 3 行 |
| 7（可选） | 网页文字长截图 | 浏览器 | 分屏合并后的断句正确率 |

## 3. 跑分流程（每张样本 × 每个模型）

1. 打开聊天，发送图片 + 文字「请识别并分析这张截图」
2. 记录 AI 是否成功返回图片内容摘要（非失败兜底/空回复）
3. 对照样本的期望关键信息，逐项核对识别结果：
   - 内容完整度：关键句子/字段是否齐全
   - 文字正确率：有无明显错字、漏字、串行
   - 顺序正确性：对话顺序是否保持
4. 每张样本给三档评分：A=可完整复用 / B=部分可用（个别错漏）/ C=不可用

## 5. 判定标准（回填后照此选择 C1 范围）

- 达标：≥ 5/7 样本 A 或 B，且聊天截图类（1-2）无 C。
- 两模型都达标 → C1 全量：多图逐张识别合并 + 注入格式统一 + 失败提示优化。
- 仅一个达标 → C1 全量但默认路由用达标厂商的 vision 模型。
- 都不达标 → C1 收缩：prompt 优化（截图识别专用描述模板）+ 失败提示优化；多图合并延后到换用更强视觉模型后。
