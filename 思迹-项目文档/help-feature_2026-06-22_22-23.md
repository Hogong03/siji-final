# 使用说明功能 — 设置子页面 + 思迹页面 AI 说明面板

## 新增文件

### `pages/settings/sub/help.vue` — 使用说明子页面
- 5 个 Tab 导航：思迹 AI / 日记 / 记账 / 计划 / 设置
- **思迹 AI**：核心理念、6 种说话示例（记账/日记/计划/复合/查询/撤销）、快捷短语说明、语音输入、高风险确认、结果可编辑、多轮对话、多模型切换
- **日记**：创建方式、心情选择、标签管理、标签筛选、语音录入、按月浏览
- **记账**：快速记账三种方式、月度预算、分类筛选、备注搜索、日期分组、左滑操作、数字键盘
- **计划**：创建方式、优先级、子任务、标签、统计看板、模板系统、倒计时
- **设置**：AI 模型配置、数据同步导出、外观主题、应用锁、体验反馈、隐私说明
