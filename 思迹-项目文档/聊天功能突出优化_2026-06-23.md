# 聊天界面功能突出与计划详情优化

## 执行时间
2026-06-23 02:51 — 03:05

## 改动概述
1. 输入区快捷功能按钮从灰底改为黑底白字突出显示
2. AI 创建计划时强制生成详细内容（description + subtasks）
3. 执行结果卡片展示计划详情（描述 + 子任务列表）
4. 日记结果卡片增加内容预览
5. 欢迎语重新排版，功能入口更清晰

## 详细改动

### 1. InputArea.vue — 快捷功能入口突出
- 原来灰底黑字的 `phrase-chip` → 改为**黑底白字**的 `action-chip`
- 4 个功能入口：¥记账 / ✎日记 / ✓计划 / ?查询
- 点击后填充示例占位文本到输入框

### 2. MessageBubble.vue — 结果卡片展示更多详情
**计划结果卡片**：
- 原来只显示标题 + 子任务数量
- 现在显示：标题 + description 描述 + 子任务列表（每项带 ○ 标记）

**日记结果卡片**：
- 原来只显示标题 + 心情标签
- 现在增加：content 内容预览（前 60 字）

### 3. store/index.js — 返回更丰富的 detail
- `execCreateDiary` 返回 detail 增加 content、tags
- `execCreatePlan` 返回 detail 增加 description、priority、subtasks（完整列表）、deadline

### 4. api.js — System Prompt 强化
**create_plan**：
- 标注"重要：计划必须包含详细内容"
- description 要求 30-80 字说明目标/背景/预期成果
- subtasks 要求 3-8 个具体可执行动作
- 附带示例：用户说"下周完成报告" → 4 个子任务

**create_diary**：
- content 要求至少 30 字，尽量丰富细节

### 5. chat/index.vue — 欢迎语优化
- 用功能图标 ¥ ✎ ✓ ? 对应四个功能
- 排版更清晰，复合意图单独说明
