# 设置页 AI 配置优化 — 主页摘要 + 子页面全配置

## 改动概要
设置主页的 AI 配置从「内联5厂商选择器+Key输入+模型单选」压缩为**摘要卡片**（显示当前厂商/模型/配置状态），点击进入**新建子页面 `ai.vue`** 进行完整配置。

## 文件变更

### 1. `pages/settings/index.vue` — 主设置页（重写 AI 区）
- 移除：5厂商分段控制器、Key输入行、模型单选组、应用按钮等全部内联AI逻辑
- 新增：摘要卡片（厂商图标 + 厂商名 + 模型名 + 配置状态点 + 箭头）
- 点击卡片跳转 `ai.vue`
- 脚本从 ~80 行精简到 ~40 行

### 2. `pages/settings/sub/ai.vue` — 新建 AI 配置子页面
- **厂商列表**：5个厂商卡片，点击展开/收起
- 每个厂商卡片：图标 + 名称 + 模型概览 + Key配置状态点
- 展开后：
  - "当前使用"标识（绿色）
  - API Key 输入（保存 + 测试连接）
  - 模型列表（tag + 名称 + 描述 + 勾选标记）
  - 切换按钮（如选择非当前厂商）
- 底部说明卡：Key本地存储、可多厂商配置等提示

### 3. `pages.json` — 注册路由
- 新增 `pages/settings/sub/ai` 路由

## 设计要点
| 维度 | 主页 | 子页面 |
|------|------|--------|
| 信息 | 厂商名+模型名+状态 | 全部5厂商完整配置 |
| 交互 | 点击跳转 | 展开收起+Key输入+模型选择+测试 |
| 状态 | 只读摘要 | 可编辑 |
