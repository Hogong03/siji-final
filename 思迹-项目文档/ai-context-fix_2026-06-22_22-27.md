# AI 上下文记忆修复 — 原始回复与展示文本分离

## 问题
AI 聊天不会记忆上下文内容。根因：

### 根因分析
1. **`persistHistory` 保存的是 UI 展示文本而非 AI 原始回复**
   - `autoExecuteAndDisplay` 中 `displayContent = reply + '\n\n✅ 记账成功 -¥35 (餐饮)'`
   - 然后 `updateLastMessage({ content: displayContent })` 覆盖了 message.content
   - `persistHistory` 保存 `m.content` → 传给 AI 的历史是 `"已记账 ✅\n\n✅ 记账成功 -¥35 (餐饮)"`
   - AI 看到的不是自己之前的自然语言回复，而是带执行结果后缀的格式化文本

2. **错误消息也会被持久化**
   - 请求失败时 `updateLastMessage({ content: '❌ API 请求失败' })`
   - 如果 `persistHistory` 在此之后调用，错误消息进入历史

## 修复方案
给 message 增加 `aiReply` 字段保存 AI 原始回复，`persistHistory` 优先使用 `aiReply`。

### 改动文件

#### `store/index.js` — `persistHistory()`
- 优先保存 `m.aiReply || m.content`
- 过滤掉错误消息（content 以 `❌`/`⚠️` 开头且无 aiReply）和 loading 占位消息

#### `pages/chat/index.vue` — 4 处 `updateLastMessage`
- `autoExecuteAndDisplay` 单意图：新增 `aiReply: reply`
- `autoExecuteAndDisplay` 多意图：新增 `aiReply: reply`
- `handleConfirmAction` 多意图：新增 `aiReply: pendingReply.value`
- `handleConfirmAction` 单意图：新增 `aiReply: pendingReply.value`

## 数据流（修复后）
```
用户: "午饭花了35"
AI回复: "已帮你记了一笔餐饮支出35元～"  ← aiReply
展示文本: "已帮你记了一笔餐饮支出35元～\n\n✅ 记账成功 -¥35 (餐饮)"  ← content

persistHistory 保存: "已帮你记了一笔餐饮支出35元～"  ← aiReply
下次对话 getRecentHistory 读取: "已帮你记了一笔餐饮支出35元～"  ← 自然语言
```
