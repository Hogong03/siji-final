# AI 模型配置功能优化

## 执行时间
2026-06-23 02:16 - 02:40

## 改动概述
1. 更新 5 家厂商模型列表为最新（2026-06）
2. 新增自定义模型名称输入
3. 思迹主页导航栏 badge 可点击弹出模型快速切换面板

## 详细改动

### 1. 模型列表更新（utils/api.js → AI_PROVIDERS）

| 厂商 | 旧模型 | 新增模型 |
|------|--------|----------|
| DeepSeek | deepseek-chat, deepseek-reasoner | 不变（V3+R1 仍最新） |
| OpenAI | gpt-4o-mini, gpt-4o | + gpt-5 |
| Moonshot | moonshot-v1-8k, moonshot-v1-32k | + **kimi-k2.6**（K2 系列已于 2026-05-25 下线） |
| 智谱 GLM | glm-4-flash, glm-4 | + glm-4.5, + glm-5, + glm-5.1 |
| 通义千问 | qwen-turbo, qwen-plus | + qwen3.7-max, + qwen3.7-plus |

每个厂商新增 `docs` 字段（申请地址），配置页可点击跳转。

### 2. 自定义模型支持（store/index.js）

新增 3 个方法：
- `setCustomModel(provider, modelName)` — 保存/清除自定义模型
- `getCustomModel(provider)` — 读取自定义模型
- `getAvailableModels(provider)` — 获取预设 + 自定义合并列表

自定义模型存储在 `siji_custom_model_{provider}` key 中。

### 3. AI 配置页重建（pages/settings/sub/ai.vue）

- 新增「自定义模型名称」输入区
- 新增「申请地址」链接（点击打开文档/复制链接）
- 模型列表改为从 `store.getAvailableModels()` 动态获取
- 自定义模型项显示 🔧 标记

### 4. 思迹主页模型快速切换（pages/chat/index.vue）

- 导航栏 modelLabel badge 加 `▾` 箭头 + 点击事件
- 弹出 Modal 包含：
  - 厂商网格（只显示已配置 Key 的厂商）
  - 当前厂商的模型列表（含自定义）
  - 「⚙️ 高级配置」跳转到 AI 配置页
  - 未配置 Key 时显示引导按钮

## 验证
- ✅ 26 Vue + 11 JS 语法检查全部通过
