# 标签系统 — 自定义标签 + 按标签分类

## 改动文件（6 个）

### 数据层
**`utils/storage.js`** — 新增标签管理 API：
- `getUsedTags(type)` — 从实际数据中提取所有标签（按使用次数降序）
- `addCustomTag(type, name)` — 添加自定义标签到注册表（自动分配颜色）
- `removeCustomTag(type, name)` — 删除标签
- 内置 15 色调色板，冲突自动回避

**`store/index.js`** — 计划数据结构新增 `tags: []` 字段：
- `execCreatePlan` 支持 `p.tags`
- `createPlanFromTemplate` 支持 `tpl.plan_data.tags`

### UI 层
**`pages/plan/detail.vue`** ⭐ 核心改造：
- 标签区：chip 样式显示已选标签 → 点击移除
- `+ 添加标签` 按钮 → 底部弹出标签选择器
- 选择器：已用标签列表（带使用次数）+ 右下角勾选 + 底部输入框创建新标签

**`pages/plan/index.vue`** ⭐ 按标签分类：
- 状态筛选 + 优先级筛选 下方新增标签筛选行
- 显示所有使用中的标签及数量（如「工作 3」「学习 2」）
- 点击高亮（厂商主题色），再次点击取消
- 配合状态/优先级筛选叠加使用

**`pages/diary/detail.vue`** ⭐ 同样改造：
- 标签从旧的 JSON 文本输入框 → chip 样式交互
- 同样底层弹出标签选择器

**`pages/diary/list.vue`** — 标签兼容：
- `getItemTags()` 兼容数组和旧 JSON 字符串格式
- 卡片上显示 `#标签1 #标签2`

## 设计决策
1. **标签从数据中提取而非手工注册**：`getUsedTags()` 遍历所有计划/日记实时统计，避免注册表与数据不一致
2. **颜色自动分配**：15 色调色板循环使用，已用颜色跳过
3. **向后兼容**：日记 `tags` 字段支持 `String`(JSON) 和 `Array` 两种格式
4. **标签筛选叠加**：状态 × 优先级 × 标签 三维筛选可任意组合
