### 通用替换规则
| 旧值 | 新值 |
|------|------|
| `#6366F1` | `#000000`（CSS）/ `#18181B`（JS 文字色） |
| `#8B5CF6` | `#3F3F46` |
| `#4F46E5` | `#18181B` |
| `linear-gradient(135deg, #6366F1..., #8B5CF6...)` | `#000000` |
| `backdrop-filter: blur(...)` | 删除 |
| `$ai-primary` | `#000000` |
| `$shadow-ai` | `none` |
| `var(--glass-bg)` | `#FFFFFF` |
| `.breathing` animation | 删除 |

| `rgba(102, 126, 234, 0.x)` | `rgba(0, 0, 0, 0.0x)` |

## 设计规范（方案 C 极简未来）
- 色彩层级：`#FFFFFF` → `#F4F4F5` → `#E4E4E7` → `#000000`
- 文字层级：`#18181B` → `#71717A` → `#94A3B8`
- 功能色仅用于数据：记账 `#F59E0B`、计划 `#10B981`、日记 `#FCD34D`
- 零渐变、零模糊、零阴影装饰
