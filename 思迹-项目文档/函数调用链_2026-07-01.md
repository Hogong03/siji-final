# 思迹（Siji）项目函数调用链

## 一、整体架构分层

```
┌─────────────────────────────────────────────────┐
│                  页面层 (pages/)                  │
│  chat / bill / plan / diary / settings / lock    │
├─────────────────────────────────────────────────┤
│                组件层 (components/)                │
│  MessageBubble / InputArea / ExecResultCard      │
│  VoiceButton / EmptyState                        │
├─────────────────────────────────────────────────┤
│              状态管理层 (store/)                   │
│  useAppStore (聚合) → chat / data / aiConfig      │
│                       agent / theme / device      │
├─────────────────────────────────────────────────┤
│              工具层 (utils/)                       │
│  api / storage / sync / reminder / memory         │
│  voice / theme / pin / uuid / logger / debounce   │
│  categories / device                              │
└─────────────────────────────────────────────────┘
```

## 三、核心：AI 对话调用链（最重要）

```
用户输入文字
  └→ InputArea.vue @send
      └→ chat/index.vue handleSend(text)
          │
          ├─ 1. 前置检查
          │   ├→ store.hasApiKey                  // store/aiConfig.js
          │   └→ isOnline()                        // utils/api.js
          │
          ├─ 2. 构建历史上下文
          │   └→ store.messages (filter+map)       // store/chat.js
          │       └→ 附加 execResult 摘要 + client_id
          │
          ├─ 3. 添加消息到界面
          │   ├→ store.addMessage({ role: 'user' })
          │   ├→ store.addMessage({ role: 'assistant', loading: true })
          │   └→ inputAreaRef.reset()
          │
          ├─ 4. 构建 AI 请求配置
          │   ├→ store.getAgentSystemPrompt(activeAgentId)  // store/agent.js
          │   └→ cfg = { provider, model, apiKey, systemPrompt, temperature }
          │
          ├─ 5. 流式请求 AI
          │   └→ chatRequestStream(message, convId, cfg, onChunk, history)
          │       │  // utils/api.js
          │       ├─ [H5 有 fetch+ReadableStream] →
          │       │   chatRequestRealStream()      // 真实 SSE 流式
          │       │   ├→ fetch(provider.endpoint, { stream: true })
          │       │   ├→ ReadableStream reader.read()
          │       │   ├→ onChunk(delta) → store.updateLastMessage()
          │       │   └→ parseAiResponse(fullContent)
          │       │
          │       └─ [不支持 SSE] →
          │           simulatedStream()             // 模拟流式
          │           ├→ uni.request() → parseAiResponse()
          │           └→ onChunk(chunk) 每 2 字 / 8ms
          │
          ├─ 6. 解析 AI 响应
          │   └→ parseAiResponse(raw, convId)       // utils/api.js
          │       ├→ JSON.parse() 优先
          │       ├→ 正则提取 ```json``` 块
          │       └→ return { reply, action, actions, suggestions, conversation_id }
          │
          ├─ 7. 执行操作（分两条路径）
          │   │
          │   ├─ [需确认 needConfirm=true] →
          │   │   store.updateLastMessage({ pendingAction, pendingActions })
          │   │   └→ 用户点击确认 → handleConfirmAction()
          │   │       └→ store.executeAction(pendingAction)
          │   │       └→ store.executeActions(pendingActions)
          │   │
          │   └─ [自动执行] → autoExecuteAndDisplay(result, reply)
          │       │
          │       ├─ [多操作] → store.executeActions(actions)
          │       │   │  // store/data.js
          │       │   └─ 遍历 actions → executeAction(action) 逐个执行
          │       │       └→ 收集 results[] 返回 { allSuccess, message, results }
          │       │
          │       └─ [单操作] → store.executeAction(action)
          │           │  // store/data.js
          │           └─ switch(action.type)
          │               ├─ create_diary    → execCreateDiary(p)
          │               │   ├→ generateEntityId('diary')     // utils/uuid.js
          │               │   ├→ saveDiary(diary)              // utils/storage.js
          │               │   ├→ updateIndex('diary', diary)   // utils/storage.js
          │               │   ├→ enqueue({ type:'diary', ... })// utils/sync.js
          │               │   └→ return { success, message, detail }
          │               │
          │               ├─ create_bill     → execCreateBill(p)
          │               │   ├→ generateEntityId('bill')
          │               │   ├→ saveBill(bill)                // utils/storage.js
          │               │   ├→ updateIndex('bill', bill)
          │               │   ├→ enqueue({ type:'bill', ... })
          │               │   └→ return { success, message, detail }
          │               │
          │               ├─ create_plan     → execCreatePlan(p)
          │               │   ├→ generateEntityId('plan')
          │               │   ├→ savePlan(plan)                // utils/storage.js
          │               │   ├→ updateIndex('plan', plan)
          │               │   ├→ enqueue({ type:'plan', ... })
          │               │   └→ return { success, message, detail }
          │               │
          │               ├─ update_plan      → execUpdatePlan(p)
          │               │   ├→ getPlanList() → find by client_id
          │               │   ├→ merge updates
          │               │   ├→ savePlan(updated)
          │               │   ├→ enqueue({ action:'update' })
          │               │   └→ return { success, message, detail }
          │               │
          │               ├─ update_bill      → execUpdateBill(p)
          │               ├─ delete_bill      → execDeleteBill(p)
          │               ├─ update_diary     → execUpdateDiary(p)
          │               ├─ delete_diary     → execDeleteDiary(p)
          │               ├─ delete_plan      → execDeletePlan(p)
          │               ├─ update_plan_subtask → execUpdatePlanSubtask(p)
          │               ├─ create_plan_template → execCreatePlanTemplate(p)
          │               │
          │               ├─ query_diary      → execQueryDiary(p)
          │               │   └→ searchByIndex('diary', keyword)  // utils/storage.js
          │               │       └→ 全量 includes 降级搜索
          │               │
          │               ├─ query_bill       → execQueryBill(p)
          │               ├─ query_plan       → execQueryPlan(p)
          │               │
          │               ├─ query_stat       → execQueryStat(p)
          │               │   ├→ getBillList(month)     // utils/storage.js
          │               │   ├→ getDiaryList(month)
          │               │   ├→ getPlanList()
          │               │   └→ 聚合统计返回
          │               │
          │               └─ undo_last        → execUndo()
          │                   └→ 从撤销栈恢复上一操作
          │
          ├─ 8. 更新消息气泡
          │   └→ store.updateLastMessage({
          │       content: displayContent,
          │       aiReply: reply,
          │       actionCard: { type, payload },   // → MessageBubble 渲染卡片
          │       execResult / execResults
          │   })
          │
          ├─ 9. 长期记忆提取
          │   ├→ autoExtractMemory(message, reply, execResult)  // utils/memory.js
          │   │   └→ 正则匹配：饮食、作息、预算、偏好等
          │   │   └→ addMemory(content, category)
          │   │       └→ uni.setStorageSync('siji_memories')
          │   │
          │   └─ [每 15 轮] aiSummarizeConversation(messages, cfg)
          │       └→ chatRequest() → AI 生成摘要
          │       └→ addMemory(summary, 'summary')
          │
          └─ 10. 持久化
              └→ store.persistHistory()              // store/chat.js
                  └→ uni.setStorageSync('siji_conversations')
```

## 五、AI 请求内部调用链（utils/api.js）

```
chatRequest(message, contextType, convId, config, history)
  └→ chatRequestWithRetry(msg, convId, cfg, retryCount=0, history)
      ├→ getProvider(cfg.provider)              // 获取厂商配置
      ├→ getProviderKeys()                       // 获取所有 API Keys
      ├→ getRecentHistory()                      // 读取对话历史 (旧兼容)
      ├→ buildChatMessages(msg, history, cfg)    // 构建消息数组
      │   ├→ buildSystemPrompt()                 // 构建系统提示词
      │   │   ├→ getUserProfile()                // 读取用户画像
      │   │   │   ├→ getBillList(currentMonth)
      │   │   │   ├→ getDiaryList(currentMonth)
      │   │   │   └→ getPlanList()
      │   │   ├→ getTopCategory(expenseBills)    // 计算主要支出分类
      │   │   └→ buildMemoryContext()            // utils/memory.js — 注入记忆
      │   │       └→ getAllMemories() → filter recent → format
      │   └→ buildProviderRequest(provider, model, messages, apiKey, temp)
      │       └→ 按厂商格式构建 uni.request 参数
      │           (DeepSeek/OpenAI/Moonshot/智谱/通义 各有差异)
      │
      ├→ uni.request(reqOpts)
      │   └→ success: parseAiResponse(raw, convId)
      │       ├→ JSON.parse() 优先
      │       ├→ 正则提取 ```json``` 块
      │       └→ return { reply, action, actions, suggestions, conversation_id }
      │
      └→ 空回复自动重试 (最多 2 次)

chatRequestStream(message, convId, cfg, onChunk, history)
  ├─ [H5 有 fetch+ReadableStream] →
  │   chatRequestRealStream(msg, convId, cfg, onChunk, history)
  │   ├→ buildChatMessages() (同上)
  │   ├→ fetch(provider.endpoint, { method:'POST', stream:true })
  │   ├→ response.body.getReader()
  │   ├→ reader.read() 循环
  │   ├→ TextDecoder decode → 提取 data: JSON
  │   ├→ onChunk(delta) 实时回调
  │   └→ parseAiResponse(fullContent, convId)
  │
  └─ [不支持 SSE] →
      simulatedStream(msg, convId, cfg, onChunk, history)
      ├→ chatRequestWithRetry() → parseAiResponse()
      └→ setInterval 每 8ms 推送 2 字 → onChunk(chunk)
```

## 六、提醒系统调用链（utils/reminder.js）

```
App.vue onLaunch
  └→ initReminder(getPlanList)     // 注入数据获取函数
  └→ startReminderChecker()        // 启动定时器
      └→ setInterval → checkAllReminders() 每 60s

App.vue onShow
  └→ checkAllReminders()           // 从后台回到前台立即检查

checkAllReminders()
  ├→ getReminderSettings()         → uni.getStorageSync('siji_reminder_settings')
  ├→ _getPlanList()                → 获取全量计划
  ├→ 遍历计划 →
  │   ├→ 跳过已删除/已完成
  │   ├→ getPlanReminder(planId)   → 读取该计划的提醒配置
  │   ├→ calcReminderTime(plan, reminderCfg)
  │   │   ├→ 优先 customTime
  │   │   ├→ 否则 deadline - advanceMin
  │   │   └→ return { shouldFire, isOverdue, fireTime }
  │   │
  │   ├→ 检查是否已触发 (siji_reminders_triggered)
  │   ├→ 检查免打扰时段 (22:00~08:00)
  │   └→ [到时间] → triggerReminder(plan, reminderCfg, isOverdue)
  │       ├→ uni.vibrate()                    // 震动
  │       ├→ uni.showModal()                  // 前台弹窗
  │       │   └→ 用户点"查看" → uni.navigateTo plan/detail
  │       ├─ [App 端] plus.push.createPushMessage()  // 后台推送
  │       └─ [H5] new Notification()          // Web 通知
  │
  ├→ markTriggered(planId)          → 记录已触发
  └→ cleanupTriggered()             → 清理 7 天前的记录

计划详情页 (plan/detail.vue)
  ├→ onLoad → getPlanReminder(planId)   → 回填 UI
  └→ handleSave →
      ├→ setPlanReminder(planId, { enabled, advanceMin, customTime })
      └→ removePlanReminder(planId)     // 未开启时
```

## 九、语音输入调用链（utils/voice.js）

```
InputArea.vue
  ├→ isVoiceSupport()                // 平台检测
  ├→ startRecord({ onStart, onResult, onError })
  │   ├─ [H5] setupH5AudioPipeline()
  │   │   ├→ navigator.mediaDevices.getUserMedia()
  │   │   ├→ MediaRecorder → audioChunks
  │   │   └→ new WebSocket('wss://rtasr.xfyun.cn/v1/ws')
  │   │       ├→ crypto-js: HmacSHA1(MD5(appid+ts), api_key) → base64 → signa
  │   │       ├→ ws.send(audioData)  // 16k 16bit PCM
  │   │       └→ ws.onmessage → JSON.parse → onResult(text)
  │   │
  │   └─ [App/小程序] startAppRecording()
  │       ├→ uni.getRecorderManager()
  │       ├→ recorderManager.start({ format:'mp3' })
  │       └→ uni.connectSocket() → SocketTask
  │           └→ 同上讯飞 WebSocket 流程
  │
  └→ stopRecord()
      ├─ [H5] mediaRecorder.stop() → ws.send(final chunk) → ws.close()
      └─ [App] recorderManager.stop() → SocketTask.close()
```
