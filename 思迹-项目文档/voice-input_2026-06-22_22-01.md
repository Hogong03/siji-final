# 语音输入功能 — AI聊天框 + 日记

## 新增文件（2 个）

### 1. `utils/voice.js` — 语音输入工具
- 封装 uni-app 多平台录音 + 语音识别
- **App (plus)**: `plus.audio.getRecorder` 录音 + `plus.speech.startRecognize` 识别
- **H5**: Web Speech API (`SpeechRecognition`)
- **小程序**: `uni.getRecorderManager`（需额外插件支持识别）
- API: `startRecord()` / `stopRecord()` → 返回识别文本 / `cancelRecord()` / `isVoiceSupported()`

### 2. `components/common/VoiceButton.vue` — 可复用语音按钮
- 交互：长按 200ms 启动录音 → 松开停止并识别 → 文本通过 `@result` 事件回传
- 动画：录音中红色脉冲波纹动画 + "松开识别"提示
- 反馈：录音启动时短震动（App端）
- 不支持平台自动隐藏（`v-if="supported"`）

## 修改文件（3 个）

### 3. `components/chat/InputArea.vue` — AI聊天框
- 导入 VoiceButton 组件
- 输入行左侧新增语音按钮（textarea 前方）
- `onVoiceResult(text)`: 已有文本追加，空输入直接填入

### 4. `pages/diary/detail.vue` — 日记编辑
- 导入 VoiceButton 组件
- 标题区：section-header（标签 + 语音按钮横排）
- 正文区：同上
- `onVoiceTitle(text)`: 追加到标题
- `onVoiceContent(text)`: 追加到正文（换行分隔）
- 新增 `.section-header` flex 布局样式

### 5. `manifest.json` — 权限配置
- `modules.Speech`: 启用语音识别模块
- Android 权限: `RECORD_AUDIO` + `INTERNET`

## 技术要点

| 维度 | 说明 |
|------|------|
| 交互模式 | 长按录音（200ms阈值防误触）→ 松开识别 |
| 文本处理 | 追加模式，不覆盖已有内容 |
| 平台兼容 | App全支持 / H5依赖浏览器API / 小程序自动隐藏 |
| 权限 | Android 录音权限 + 互联网权限 |
| 模块 | App 端需 Speech 模块（manifest.json 已配置） |

## ⚠️ 风险预警
1. **HBuilderX 编译**：需确保 HBuilderX 版本支持 `plus.speech` 模块（3.x+ 均支持）
2. **iOS 隐私**：上架审核需在 Info.plist 描述麦克风用途（HBuilderX 打包时配置）
3. **离线识别**：`plus.speech` 默认使用在线识别，需网络连接
4. **浏览器兼容**：H5 端 Web Speech API 仅 Chrome/Edge 支持，Safari/Firefox 不支持（VoiceButton 会自动隐藏）
